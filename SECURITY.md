# Security Policy

## Supported Versions

Only the latest release (see [Releases](https://github.com/hakuxyz/ytop/releases)) receives updates.

## Reporting a Vulnerability

Please report security issues **privately** via GitHub Security Advisories:

https://github.com/hakuxyz/ytop/security/advisories/new

If the advisory form is not available, contact me via [GitHub](https://github.com/hakuxyz) instead. Please do not open public issues for vulnerabilities. I will acknowledge reports as quickly as possible and coordinate a fix, release and credit.
